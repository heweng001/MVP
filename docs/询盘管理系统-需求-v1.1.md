# 询盘管理系统 — 需求说明书

> 版本：v1.1  
> 日期：2026-08-01  
> 状态：已确认，作为开发依据  
> 范围：第一期 MVP，约 20+ 个 WordPress 站点（均为 WPForms Pro）

---

## 1. 背景与目标

### 1.1 背景

作为网站服务商，为多个客户搭建并维护 WordPress 网站。各站询盘表单使用 **WPForms Pro**，目前将询盘邮件直发客户邮箱。询盘以**外贸英文**为主，其中存在大量垃圾询盘（如 SEO/外链推销等），也有真实采购询盘。缺少统一沉淀、垃圾预筛，以及按站点、按月的有效询盘统计能力。

### 1.2 目标

建设一套**询盘管理系统**，实现：

1. 对接各客户 WordPress 站点的询盘表单，统一入库管理；  
2. 对询盘自动进行垃圾评分与判定：明显垃圾**不转发客户**，但保留在后台供查验；  
3. 对需转发的询盘，由系统代发邮件给客户，并在邮件中提供「有效 / 无效」标记能力；  
4. 在管理后台按**月份**、按**WordPress 站点**统计有效询盘数与有效占比等指标。

### 1.3 成功标准

| 项 | 标准 |
|----|------|
| 接入 | 约 20+ 站点可通过配置完成对接 |
| 拦截 | 评分 ≥80 的询盘不进入客户邮箱；后台可查验、可补发 |
| 审核 | 中间分经人工审核后发送；超过 6 小时未审核则自动发送 |
| 标记 | 客户无需登录系统，在邮件内完成标记；发信后 72 小时内可改判 |
| 统计 | 可按月、按站查看有效询盘数与有效占比 |

|------|------|
| 系统管理员 | 仅单管理员账号，不做权限分级 |
| 客户收件人 | 无系统登录账号；邮件内标记 |

## 3. 范围

### 3.1 In Scope（第一期）

- WordPress + WPForms Pro 询盘表单接入  
- 垃圾打分、自动拦截（≥80）、中间分人工审核（含 6 小时超时自动发）  
- 服务商域名 SMTP 代发 + 中文标记文案与确认页  
- 客户标记 / 72 小时内改判；超时未标记为独立状态 `timeout_unmarked`  
- 管理后台与月度统计  
- 系统异常时自动放行并发送  

### 3.2 Out of Scope

- 完整 CRM、客户登录门户、机器学习反垃圾、Excel 导出、定期邮件报表  
- 客户点无效自动进黑名单、上线前影子模式、多管理员权限分级  

---

## 4. 关键业务规则

### 4.1 垃圾分路径

阈值可在后台「发件设置」配置（默认：自动垃圾 ≥80，人工审核 ≥20，低于 20 直接转发）：

- ≥ 自动垃圾阈值 → `auto_spam`（自动垃圾），不发客户  
- ≥ 人工审核阈值且未达自动垃圾阈值 → `review`；审核通过则发客户；标为垃圾 → `review_spam`（不发客户）；支持批量；超 6 小时未审 → 自动发客户  
- 低于人工审核阈值 → 直接代发客户 → `pending`（待标记）  
- 管理员对未转发询盘手动标垃圾 → `review_spam`  
- 标准展示字段：姓名 / 邮箱 / phone/whatsapp / 内容（不再使用主题 subject）  

### 4.2 标记

- 发信成功起 72 小时内可标记/改判  
- 满 72 小时仍无标记 → 状态 `timeout_unmarked`（不自动改为 valid）  

### 4.3 有效统计

- **拦截** = 自动垃圾 + 审核垃圾  
- **待标记** / **超时未标记**：已转发且尚未点有效/无效（按是否满 72 小时区分展示）  
- **有效占比** = (标记有效 + 待标记 + 超时未标记) ÷ 已转发 × 100%  
- 按北京时间、询盘提交时间归属月份  

### 4.4 其它

- 多收件人/抄送，按表单配置  
- 发件：服务商域名  
- 邮件文案：中文  
- 失败降级：自动放行并发送
