# 询盘系统部署到阿里云（Node + systemd + Nginx）

与 `ai.maoniux.com` 相同：本机 Node 跑应用，Nginx 反代 + HTTPS。

## 目录约定

| 路径 | 说明 |
|------|------|
| `/opt/inquiry/repo` | git 仓库 |
| `/opt/inquiry/repo/inquiry-system` | 应用目录 |
| `/opt/inquiry/data/prod.db` | SQLite 数据库 |
| `/etc/systemd/system/inquiry-system.service` | 进程服务 |
| Nginx `mvp.maoniux.com` | 反代到 `127.0.0.1:3001` |

## 首次部署摘要

```bash
cd /opt/inquiry
git clone <仓库地址> repo
cd repo/inquiry-system

# 配置 .env（APP_URL / AUTH_SECRET / CRON_SECRET / ADMIN_* / DATABASE_URL）
# DATABASE_URL="file:/opt/inquiry/data/prod.db"
# APP_URL="https://mvp.maoniux.com"
# PORT=3001
mkdir -p /opt/inquiry/data

npm ci
npx prisma generate
npx prisma db push
npx tsx prisma/seed.ts
npm run build

# 安装 systemd（见仓库或服务器现有 inquiry-system.service）
systemctl enable --now inquiry-system

# Nginx server_name mvp.maoniux.com -> proxy_pass http://127.0.0.1:3001
# certbot --nginx -d mvp.maoniux.com
```

## 日常更新

```bash
cd /opt/inquiry/repo
git pull
cd inquiry-system
npm ci
npx prisma db push
npm run build
systemctl restart inquiry-system
```
