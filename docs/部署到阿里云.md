# 询盘系统部署到阿里云

## 一、推代码到 Git

本机已初始化仓库后，创建远程并推送，例如：

```bash
# GitHub 示例
gh repo create inquiry-system --private --source=. --remote=origin --push
# 或
git remote add origin git@github.com:你的用户名/inquiry-system.git
git push -u origin main
```

## 二、服务器准备

1. 阿里云 ECS（建议 Ubuntu 22.04），安全组放行：
   - `22`（SSH）
   - `80` / `443`（若用 Nginx）
   - 或临时 `3000`（直接访问容器端口）
2. 域名解析到服务器公网 IP（邮件标记链接需要公网 `APP_URL`）

## 三、部署步骤

```bash
# SSH 登录服务器后
sudo mkdir -p /opt/inquiry
cd /opt/inquiry
git clone <你的仓库地址> repo
cd repo/inquiry-system

cp .env.production.example .env.production
nano .env.production
# 必改：APP_URL、AUTH_SECRET、CRON_SECRET、ADMIN_PASSWORD
# 建议配置 SMTP

chmod +x ../../deploy/aliyun-setup.sh
# 若脚本在仓库根目录：
bash ../../deploy/aliyun-setup.sh "$(pwd)"

# 或直接：
docker compose up -d --build
```

浏览器打开 `APP_URL`，用管理员账号登录。

WordPress 插件 API 填写：`https://你的域名/api/ingest`

## 四、Nginx 反代示例（推荐）

```nginx
server {
  listen 80;
  server_name inquiry.your-domain.com;

  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
```

再用 certbot 配 HTTPS，并把 `.env.production` 里 `APP_URL` 改成 `https://...`。

## 五、定时任务（服务器 crontab）

```bash
crontab -e
# 每 10 分钟
*/10 * * * * curl -fsS -X POST "https://你的域名/api/cron" -H "x-cron-secret: 你的CRON_SECRET" >/dev/null
```

## 六、更新发布

```bash
cd /opt/inquiry/repo
git pull
cd inquiry-system
docker compose up -d --build
```
